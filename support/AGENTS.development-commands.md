# Development Commands

Document commands for:

- Installing dependencies.
- Starting local development.
- Formatting code.
- Running focused tests and the full test suite.
- Performing required validation.

Prefer commands already defined by the repository’s package manager, task runner, or CI
configuration.

When a command is unavailable in the current environment:

- Report that limitation.
- Use the narrowest documented alternative.
- Distinguish targeted checks from full-suite and CI-only checks.
