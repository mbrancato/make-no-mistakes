# Pull Request Guidance

Keep changes focused. In the handoff:

- Explain the user-visible or operational reason for the change.
- Summarize the implementation.
- Identify important tradeoffs.
- List validation commands and their results.

Call out:

- Known limitations and follow-up work.
- Migrations and configuration changes.
- Checks that could not be run.
- Do not claim a check passed unless it was actually executed successfully.
