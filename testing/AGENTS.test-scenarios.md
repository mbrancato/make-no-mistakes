# Test Scenarios

Group related variations as descriptively named scenarios using the active language and framework
idioms.

- Identify each failure by scenario without requiring inspection of test implementation.
- Use separate tests or classes when grouping materially different behavior would reduce clarity.
- See the applicable language guide for named-case mechanics.
